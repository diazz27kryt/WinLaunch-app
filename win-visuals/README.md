# Win Visuals

Клиентский Fabric-мод WinLaunch. Собирается для **Minecraft 1.21.11** (Fabric Loader 0.18.1, Fabric API 0.141.6+1.21.11, Java 21). Версия для 1.21.1 лежит в лаунчере отдельным jar.

## Возможности

- **Ночное небо WinLaunch** — глубокий тёмно-синий купол, звёзды, мягкие туманности и анимированные ленты северного сияния.
- **Меню Right Shift** — чёрно-белый Liquid Glass интерфейс с пятью вкладками: Небо, Визуалы, Частицы, Интерфейс и Настройки.
- **Трейлы** — цветной шлейф за движущимся игроком, включая полёт на элитрах.
- **Эффекты** — косметические эффекты прыжка, приземления и попадания.
- **Зум** — клавиша **Z** (удерживать), плавное приближение; коэффициент настраивается во вкладке Настройки.
- **HUD-индикатор** — компактная метка WIN VISUALS, которую можно отключить в меню.
- **Сохранение** — настройки записываются в `.minecraft/config/winvisuals.json`.

## Управление

- **Right Shift** — открыть или закрыть меню (клавишу можно переназначить в настройках управления).
- **Z** — зум (удерживать).
- Кнопка «Применить» сохраняет настройки и закрывает меню, «Сбросить» возвращает значения по умолчанию.

## Сборка

Нужны JDK 21 и доступ к Maven Fabric.

```sh
gradle build --no-daemon
```

Готовый JAR: `build/libs/win-visuals-1.0.0.jar`. Для запуска нужны Fabric Loader и Fabric API соответствующей версии.

## Вшивание в WinLaunch

GitHub Actions собирает мод при изменениях в `win-visuals/**`, сохраняет JAR как artifact `win-visuals` и копирует его в `ZalithLauncher/src/main/assets/winvisuals/win-visuals-1.21.11.jar`. `WinVisualsBundle.kt` выбирает jar по версии игры (1.21.1 и 1.21.11).
